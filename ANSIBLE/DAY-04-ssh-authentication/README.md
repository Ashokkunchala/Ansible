# Day 04 — SSH Authentication

## Goal
Understand key-based SSH authentication and troubleshooting.

## Example
```yaml
ssh user@host
```

## Exercises
1. Create an SSH config entry and validate connectivity.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Troubleshoot an intentional SSH failure.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
