# Day 02 — Installation & Verification

## Goal
Install Ansible on WSL/Linux and verify the controller.

## Example
```yaml
ansible --version
```

## Exercises
1. Verify ansible, ansible-playbook and installed collections.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Build a repeatable setup checklist.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
