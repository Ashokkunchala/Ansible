# Day 05 — YAML Fundamentals

## Goal
Learn YAML indentation, mappings, lists and quoting.

## Example
```yaml
name: web-server
packages:
  - nginx
  - git
```

## Exercises
1. Write application configuration in YAML.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Identify and fix indentation errors.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
