# Ansible 60-Day Curriculum

Every day contains a lesson in `README.md`. Exercises and labs are progressively added under `LABS/` and `PROJECTS/`.

## Phase 1
Days 1–10: foundations

## Phase 2
Days 11–20: variables, facts, registers, conditionals, loops, tags, handlers, templates, Vault

## Phase 3
Days 21–30: roles, Jinja2, collections, Galaxy, Molecule and testing

## Phase 4
Days 31–40: Linux, Docker, application deployment, AWS inventory and rolling deployments

## Phase 5
Days 41–50: idempotency, check/diff, become, failure handling, delegation, performance and CI

## Phase 6
Days 51–60: environments, role standards, security, secrets, CI/CD, AWS configuration, rollouts, recovery and capstone

## Rule
Do not skip ahead. Build the skill, break the automation, troubleshoot it, then proceed.
