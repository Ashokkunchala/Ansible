# Day 01 — Introduction & Architecture

## Goal
Understand control node, managed node, inventory, modules, tasks, plays and playbooks.

## Example
```yaml
ansible --version
```

## Exercises
1. Install Ansible and draw the controller-to-managed-node flow.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Explain how Ansible changes manual SSH work.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
