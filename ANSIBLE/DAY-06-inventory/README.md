# Day 06 — Inventory

## Goal
Create INI and YAML inventories and understand groups.

## Example
```yaml
[web]
web1 ansible_host=192.0.2.10
```

## Exercises
1. Build dev/stage/prod-style example groups.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Explain group and host variables.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
