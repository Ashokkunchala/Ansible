# Day 26 — Collections

## Goal
Use fully qualified collection names and manage dependencies.

## Example
```text
ansible-galaxy collection install community.general
```

## Exercises
1. Recreate the structure yourself.
2. Add a DevOps variation.
3. Validate syntax.
4. Test idempotency by running twice.

## Mini challenge
Create reusable content that can be applied to at least two host groups without copying tasks.

## Safety
Pin external collections in real projects and review third-party content before use.
