# Day 10 — Foundation Mini Project

## Goal
Combine inventory, YAML, modules and idempotent tasks.

## Example
```yaml
Build a Linux web-host configuration playbook.
```

## Exercises
1. Complete package, config, service and verification tasks.
2. Type the YAML yourself.
3. Run `ansible-playbook --syntax-check` before applying changes.
4. Break one thing intentionally and troubleshoot it.

## Mini challenge
Document how repeated runs behave.

## Safety
Use disposable VMs or containers. Never experiment on production hosts.
