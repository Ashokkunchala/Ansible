# Hands-On Labs

Use disposable Linux VMs or containers.

## Lab 01 — Ping and Inventory
Create an inventory and verify connectivity.

## Lab 02 — Package + Service
Install nginx and ensure it is enabled/started.

## Lab 03 — Template + Handler
Deploy an nginx configuration from Jinja2 and notify a handler only when it changes.

## Lab 04 — Variables + Conditionals
Configure Debian/RedHat examples with OS-specific logic.

## Lab 05 — Role
Create a reusable nginx role.

## Lab 06 — Vault
Store a non-production sample secret using Ansible Vault.

## Lab 07 — Docker
Install/manage Docker on disposable hosts.

## Lab 08 — Rolling Deployment
Deploy an application with serial batches and health checks.

## Lab 09 — CI Validation
Run YAML/syntax/lint validation in GitHub Actions.

## Lab 10 — Production Capstone
Combine roles, inventories, templates, Vault strategy, CI, check mode, verification and rollback.

Never point these labs at production systems.
