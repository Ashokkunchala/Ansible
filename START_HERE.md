# START HERE — Ansible From Zero to Production

This repository is designed for a DevOps engineer who may know cloud/Linux concepts but is new to Ansible.

You do not need prior Ansible knowledge.

## Learning path

| Phase | Days | Focus |
|---|---:|---|
| 1 | 1–10 | Ansible foundations |
| 2 | 11–20 | YAML, inventories, variables, facts, modules |
| 3 | 21–30 | Playbooks, roles, templates, handlers |
| 4 | 31–40 | AWS/Linux automation and troubleshooting |
| 5 | 41–50 | Production engineering |
| 6 | 51–60 | Projects, CI/CD, security and capstone |

## Daily method

Read → type → run → break it → fix it → complete exercises → explain it → commit.

Start with [Day 1](ANSIBLE/DAY-01-introduction/README.md).

Never run destructive playbooks against production while learning.
